# DJ Energy timing and Laya

Timed cues and selective highlights are now modes of the existing **DJ Energy** feature. Open Settings → Audio → Output & Loudness → **DJ Energy options**.

Use the **1.5 s / 80% preset** for a 70% → 80% transition. Timed mode defaults to 2:45; automatic and Laya modes apply it to selected sections. All modes use the same DJ Energy master switch.

While a song plays, **Test boost now** immediately auditions the transition. Live status shows whether the native effect is active, Laya is scoring or a playback route is suspended. Version 4.6.2 follows the active crossfade player and aligns timed cues to decoded audio rather than the screen's progress clock.

See [LAYA-DJ-FORK.md](LAYA-DJ-FORK.md) for setup, selection, bypass behavior, testing, signing and installation.
